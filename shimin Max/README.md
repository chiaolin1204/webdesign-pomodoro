# Tomodoro - 你的專屬番茄鐘麻吉

以番茄鐘專注流程、任務管理和角色換裝為核心的前端網站。完成專注後可獲得金幣、記錄每日收成，並用金幣解鎖角色造型。

## 頁面（共 4 個功能頁）

| 頁面 | 用途 |
|---|---|
| 專注計時 | 顯示角色、目前專注任務及倒數計時；可開始、暫停、重置或跳過計時，使用預設加減按鈕或雙擊數字輸入專注分鐘、休息分鐘與番茄數，並切換鈴聲。 |
| 待辦清單 | 新增任務、標記完成、刪除任務，並選擇目前要專注的任務及查看累積專注時間。 |
| 換裝商店 | 預覽角色並依部位篩選造型；解鎖或裝備服飾、選擇不裝備項目、調整配色，並使用預覽模式試穿。 |
| 收成紀錄 | 查看今日總專注時間與各任務收成、每週專注紀錄，以及依日期瀏覽的 28 天專注熱力圖。 |

> 網站採單頁式結構，以上四個頁面是 `index.html` 中切換顯示的內容區塊，不是四個獨立的 HTML 檔案。

## 功能依檔案類型分類

### HTML：`index.html`

1. 建立網站導覽列及金幣顯示區。
2. 建立「專注計時」區：角色圖層、目前任務、倒數計時、開始／暫停／跳過與重置按鈕、計時設定和鈴聲開關。
3. 建立「待辦清單」區：任務輸入欄位與任務列表。
4. 建立「換裝商店」區：角色預覽、商品分類、商品網格、預覽模式與調色工具。
5. 建立「收成紀錄」區：今日時間、任務明細、每週紀錄與熱力圖。
6. 提供商店購買確認對話視窗，並載入 `style.css`、`tomoto.js` 和提示音檔。

### CSS：`style.css`

1. 設定全站色彩、字型、按鈕、卡片、導覽列與頁面版型。
2. 排列計時器、角色、待辦清單、換裝商店和收成紀錄的 UI。
3. 以 `z-index` 和定位方式疊放角色 PNG 圖層，並設定商品縮圖、選取狀態和解鎖狀態。
4. 設定商店購買確認對話視窗樣式。
5. 使用響應式 CSS 調整窄螢幕上的頁面排版。

### JavaScript：`tomoto.js`

1. **專注計時**：執行專注與休息循環、暫停／繼續、跳過／重置、鈴聲提示及番茄數更新。
2. **計時設定**：以加減按鈕或雙擊數字直接輸入專注分鐘、休息分鐘和番茄數；按「套用設定」檢查數值並更新計時器。
3. **待辦清單**：新增、完成／取消完成、刪除任務，選擇目前專注任務並累計任務時間。
4. **金幣與獎勵**：依完成的專注時間計算金幣；在商店購買未解鎖的造型。
5. **換裝商店**：依類別產生商品、套用或預覽造型、處理無須裝備的項目、切換預覽模式及變更角色配色。
6. **收成紀錄**：累計每日和任務專注時間，顯示今日收成、每週專注狀態及 28 天熱力圖。
7. **瀏覽器儲存**：使用 `localStorage` 保存任務、金幣、解鎖項目、配色與專注紀錄。

## 換裝商店使用規則

### 商品解鎖與購買

1. 進入「換裝商店」，可用分類按鈕篩選部位，或在「全部」查看所有商品。
2. 每個部位名稱以「01」結尾的基本款預設已解鎖；辮髮、呆毛和外套的「無」也可免費直接選用，不需解鎖。
3. 其他未解鎖商品會顯示鎖頭與所需金幣。點選商品後會出現購買確認；確認後若金幣足夠，系統會扣款、解鎖並立即裝備。解鎖只需購買一次，之後選用該商品不再扣金幣。
4. 金幣不足時無法購買，系統會提示金幣不足；可完成專注時段賺取金幣後再購買。
5. 每個部位同一時間只能選用一項造型；選擇同部位的另一款會取代目前款式。選擇「無」會隱藏該部位的圖層。
6. 已解鎖商品與金幣會保存在目前瀏覽器；目前穿戴的造型選擇不會跨重新載入保存，重新開啟頁面會回到程式預設造型。

| 部位 | 解鎖一件未解鎖商品的價格 |
|---|---:|
| 辮髮、後髮、眼睛、嘴巴、瀏海、鞋子 | 5 金幣 |
| 呆毛、眉毛 | 2 金幣 |
| 身體、衣服、外套 | 30 金幣 |

### 金幣如何取得與扣除

- 新使用者的預設金幣為 **120 枚**；金幣餘額會顯示在側邊欄。
- 每完成一段專注計時就獲得金幣，依該段設定的專注分鐘計算：每完整 5 分鐘得 4 枚，不足 5 分鐘的餘數再得 1 枚。例如專注 25 分鐘得 20 枚，專注 26 分鐘得 21 枚。
- 金幣是在專注階段結束時發放；暫停或跳過／重置不會發放該段的完整時長獎勵。專注時間即使被中斷，仍可能記入收成紀錄，但不等同完成該段並領取金幣。
- 只有購買未解鎖商品會扣金幣；已解鎖商品的再次選用、免費基本款和「無」都不扣金幣。調整商品顏色不扣金幣。

### 預覽模式

- 開啟角色旁的「預覽模式」後，點選商品會暫時套用到商店的角色預覽，即使商品尚未解鎖也可以試穿；此模式不會顯示購買鎖頭，也不會扣金幣或解鎖商品。
- 關閉預覽模式後，角色會恢復為進入預覽前實際選用的裝備；預覽選擇不會取代正式裝備。
- 預設色、自訂色和滴管調色會立即套用至目前部位的角色圖層及商店縮圖，並儲存在瀏覽器；預覽模式只暫存造型選擇，關閉時不會還原顏色。

## 收成與熱力圖運作機制

所有日期依使用者裝置的本地日期計算。專注中的經過時間會持續累加，並儲存在瀏覽器的 `localStorage`；暫停或重置時也會補記當下已完成的專注時間。因此即使只專注一小段時間、尚未完成整輪番茄鐘，也會留下紀錄。休息時間不計入專注收成。收成畫面在開啟網站和記錄專注時間時更新；網站不會在背景於午夜自動刷新畫面。

### 今日收成：任務明細中的番茄

- 今日總時數以當天所有專注時間加總，顯示為小時與分鐘；不到一分鐘的秒數不會顯示在總時數中。
- 各任務明細的番茄依「該任務今天累計的專注時間」計算，每滿 **10 分鐘**增加一顆；未滿 10 分鐘不顯示番茄。計算採整數向下取整，例如 9 分鐘是 0 顆、20 分鐘是 2 顆。
- 每個任務列最多顯示 **15 顆**番茄；超過 150 分鐘仍會繼續累計任務時間，但圖示不再增加。
- 任務明細只列出今天有專注時間、且仍存在於待辦清單中的任務。若專注時沒有選擇任務，時間仍會加入今日總時數、週簽到和熱力圖，但不會歸到任何任務列。
- 「今日」以本地午夜為界：跨過午夜後，新專注時間記到新日期，番茄數由新一天的任務累計重新計算；舊日期紀錄不會被清除，仍保存在瀏覽器中。今日任務列每頁最多顯示 3 個任務，可用頁面底部的箭頭翻頁。

### 一到日簽到番茄

- 簽到區每次顯示本週 **星期一到星期日**，不是從今天往前數七天。
- 當某一天累計到任何大於 0 的專注時間，該日番茄就會填色；不要求完成一整個專注時段或累積滿 10 分鐘。未專注的日期顯示空心番茄。
- 新的一週開始後，下次開啟網站或更新收成時，星期欄位會切換到新一週的日期；舊日期不會移入新週或被刪除，仍可在熱力圖查看。週簽到不會重置或清除專注資料。

### 近期耕耘紀錄（28 天）熱力圖

- 每格代表一個本地日期，滑鼠移到格子上可查看日期與當日專注時數。只要當日有任何專注時間，格子就會顯示日期數字和時數；即使時間不到 10 分鐘，也會顯示數字，但底色仍是第 0 級。
- 底色依「當日總專注時間」分級，不是依番茄數；時間會將同一天的多段專注合併計算：

| 等級／顏色 | 當日專注時間 |
|---|---|
| 0／白色 | 0 到 10 分鐘（含剛好 10 分鐘） |
| 1／淡橘 `#FDE3D2` | 超過 10 分鐘，至 1 小時（含 1 小時） |
| 2／橘色 `#F6A36F` | 超過 1 小時，未滿 3 小時 |
| 3／橘紅 `#F08A5D` | 3 到 5 小時（含兩端） |
| 4／深橘紅 `#E76F51` | 超過 5 小時 |

- 每頁的時間範圍最多 28 天，版面以 7 欄、4 列呈現；有多頁時可用箭頭翻頁。首次有專注紀錄時建立第一段紀錄，持續使用時每跨入下一個 28 天區間就會增加一頁。
- 如果相鄰兩筆「有專注的日期」相差 **超過 7 天**（中間至少有 7 個完整日期沒有專注），之後再次專注時會建立新的紀錄段／頁面。舊段會保留最後專注日後最多 7 天的空白日期；新段從再次專注的日期開始。例如週一有專注，接著停用超過一週，到之後的週二再使用，熱力圖會另開一段，舊日期留在舊段。
- 間隔 **7 天或更少**就再次專注，會延續原本的日期段，中間未專注的日期以白色格子呈現；若跨過 28 天區間，仍會依每 28 天分頁。
- 閒置本身不會在背景自動建立頁面：頁面會在網站重新計算熱力圖（開啟頁面或記錄新的專注時間）時，依已保存的日期和目前日期產生。閒置超過一週後，通常要等再次專注產生新日期紀錄，才會形成新的紀錄段。
- 紀錄不會因每日或每週切換而清空。若回到過去的日子使用，仍會依實際日期加入或更新相應格子；資料可保留多久取決於瀏覽器是否仍保留網站的 `localStorage`。

### PNG：`images/avatar/`

角色採多張透明 PNG 疊圖組成。依檔名可辨識的素材分類如下：

| 分類 | 檔名類型 | 用途 |
|---|---|---|
| 辮髮 | `hair_ext_*` | 角色辮髮圖層。 |
| 身體 | `body_*` | 角色身體圖層。 |
| 後髮 | `hair_back_*` | 後髮造型圖層。 |
| 呆毛 | `ahoge_*` | 呆毛造型圖層。 |
| 眼睛 | `eye*` | 眼睛圖層與眼睛素材。 |
| 瀏海 | `hair_front_*` | 瀏海造型圖層。 |
| 眉毛 | `eyebrow_*` | 眉毛圖層。 |
| 嘴巴 | `mouth_*` | 嘴巴素材。 |
| 衣服 | `clothes_base_*` | 角色基礎服裝素材。 |
| 外套 | `clothes_outer_*` | 外套圖層。 |
| 鞋子 | `shoes_*` | 鞋子圖層。 |

部分素材以 `_mask`（可上色遮罩）和 `_line`（線稿）兩張圖成對使用；也有直接使用單張原色 PNG 的素材。資料夾內有些圖檔目前未列為商店商品，保留作為可用素材。

## 使用技術

- HTML5、CSS3、原生 JavaScript（Vanilla JavaScript），不使用前端框架。
- CSS Flexbox／Grid、Media Queries 與 CSS Mask，用於響應式版面及角色圖層上色。
- SVG：由 JavaScript 動態產生收成紀錄中的番茄圖示。
- `localStorage`：在使用者的瀏覽器保存網站資料。
- HTML `<dialog>`：呈現商店購買確認視窗。
- Font Awesome 6.4.0 CDN：提供介面圖示。
- Google Fonts：使用 Nunito 與 Noto Sans TC 字型。
- EyeDropper API：在支援的瀏覽器中吸取螢幕顏色；不支援時仍可使用自訂色盤。
- GitHub Pages：可部署此純靜態網站；不需要後端伺服器或建置指令。

## 上傳 GitHub Pages

本專案放在 `chiaolin1204/webdesign-pomodoro` repository 的 `shimin Max/` 子資料夾，不需要移動到 repository 根目錄。GitHub Pages 的發布來源仍設定為 repository 根目錄；Pages 會一併發布其中的子資料夾。

1. 將本專案檔案放在 repository 的 `main` 分支 `shimin Max/` 資料夾內，確認該資料夾包含 `index.html`、`style.css`、`tomoto.js`、`running-out-of-time.mp3` 和 `images/avatar/`。
2. 開啟 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 **Branch：`main`**、資料夾 **`/ (root)`**，再按 **Save**。這裡的 `/ (root)` 是 Pages 發布來源，並不代表要把本專案移出 `shimin Max/`。
5. 等待 GitHub Pages 部署完成後，從以下網址開啟此專案：  
   `https://chiaolin1204.github.io/webdesign-pomodoro/shimin%20Max/`
6. 後續更新 `shimin Max/` 內的檔案並推送到 `main` 分支後，GitHub Pages 會重新部署。

## 備註

- 任務、金幣與收成等資料只保存在目前瀏覽器的 `localStorage`，不會自動同步到其他裝置或瀏覽器；清除瀏覽器網站資料也可能一併移除這些資料。
- Font Awesome 與 Google Fonts 由外部 CDN 載入，使用時需要網路連線；若無法連線，網站核心互動仍由本地檔案提供，但外部圖示或字型可能無法顯示。
- GitHub Pages 對檔名大小寫敏感；HTML、CSS 和 JavaScript 中的圖片路徑需與上傳後的資料夾及檔名一致。
- HTML、CSS、JavaScript、音效和角色圖均使用相對路徑；保留 `shimin Max/` 下原有檔案與 `images/avatar/` 結構即可在上述子資料夾網址載入，不需要在路徑前加 `/`。
- 資料夾名稱含空格，網址中以 `%20` 表示；若重新命名資料夾，網站網址也會隨之改變。
