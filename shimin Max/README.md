# Tomodoro - 你的專屬番茄鐘麻吉

以番茄鐘專注流程、任務管理和角色換裝為核心的前端網站。完成專注後可獲得金幣、記錄每日收成，並用金幣解鎖角色造型。

## 頁面（共 4 個功能頁）

| 頁面 | 用途 |
|---|---|
| 專注計時 | 顯示角色、目前專注任務及倒數計時；可開始、暫停、重置或跳過計時，使用預設加減按鈕或自訂專注分鐘、休息分鐘與番茄數，並切換鈴聲。 |
| 待辦清單 | 新增任務、標記完成、刪除任務，並選擇目前要專注的任務及查看累積專注時間。 |
| 換裝商店 | 預覽角色並依部位篩選造型；解鎖或裝備服飾、選擇不裝備項目、調整配色，並使用預覽模式試穿。 |
| 收成紀錄 | 查看今日總專注時間與各任務收成、每週專注紀錄，以及依日期瀏覽的 28 天專注熱力圖。 |

> 網站採單頁式結構，以上四個頁面是 `index.html` 中切換顯示的內容區塊，不是四個獨立的 HTML 檔案。

## 專案檔案及資料夾

```text
專案根目錄/
├── index.html
├── style.css
├── tomoto.js
├── running-out-of-time.mp3
├── README.md
└── images/
    └── avatar/
        └── *.png
```

| 檔案／資料夾 | 用途 |
|---|---|
| `index.html` | 網站入口；包含共用導覽列、四個功能頁面的 HTML、計時與商店對話視窗，以及音效和 CSS／JavaScript 引用。 |
| `style.css` | 網站視覺樣式、角色圖層與商店卡片樣式、收成紀錄版面及不同螢幕尺寸的響應式排版。 |
| `tomoto.js` | 計時、任務、金幣、商店換裝、配色、資料儲存及收成統計等互動功能。 |
| `images/avatar/` | 紙娃角色與服飾的 PNG 圖層素材。 |
| `running-out-of-time.mp3` | 專注或休息階段結束時播放的提示音。 |
| `README.md` | 專案功能、檔案用途、使用技術及部署說明。 |

## 功能依檔案類型分類

### HTML：`index.html`

1. 建立網站導覽列及金幣顯示區。
2. 建立「專注計時」區：角色圖層、目前任務、倒數計時、開始／暫停／跳過與重置按鈕、計時設定和鈴聲開關。
3. 建立「待辦清單」區：任務輸入欄位與任務列表。
4. 建立「換裝商店」區：角色預覽、商品分類、商品網格、預覽模式與調色工具。
5. 建立「收成紀錄」區：今日時間、任務明細、每週紀錄與熱力圖。
6. 提供購買確認、自訂計時設定等對話視窗，並載入 `style.css`、`tomoto.js` 和提示音檔。

### CSS：`style.css`

1. 設定全站色彩、字型、按鈕、卡片、導覽列與頁面版型。
2. 排列計時器、角色、待辦清單、換裝商店和收成紀錄的 UI。
3. 以 `z-index` 和定位方式疊放角色 PNG 圖層，並設定商品縮圖、選取狀態和解鎖狀態。
4. 設定自訂設定及購買確認對話視窗樣式。
5. 使用響應式 CSS 調整窄螢幕上的頁面排版。

### JavaScript：`tomoto.js`

1. **專注計時**：執行專注與休息循環、暫停／繼續、跳過／重置、鈴聲提示及番茄數更新。
2. **計時設定**：以加減按鈕或自訂欄位設定專注分鐘、休息分鐘和番茄數；檢查有效輸入，套用後更新計時器。
3. **待辦清單**：新增、完成／取消完成、刪除任務，選擇目前專注任務並累計任務時間。
4. **金幣與獎勵**：依完成的專注時間計算金幣；在商店購買未解鎖的造型。
5. **換裝商店**：依類別產生商品、套用或預覽造型、處理無須裝備的項目、切換預覽模式及變更角色配色。
6. **收成紀錄**：累計每日和任務專注時間，顯示今日收成、每週專注狀態及 28 天熱力圖。
7. **瀏覽器儲存**：使用 `localStorage` 保存任務、金幣、解鎖項目、配色與專注紀錄。

### PNG：`images/avatar/`

角色採多張透明 PNG 疊圖組成。依檔名可辨識的素材分類如下：

| 分類 | 檔名類型 | 用途 |
|---|---|---|
| 辮髮 | `hair_ext_*` | 角色辮髮圖層。 |
| 身體 | `body_*` | 角色身體圖層。 |
| 後髮 | `hair_back_*` | 後髮造型圖層。 |
| 呆毛 | `ahoge_*` | 呆毛造型圖層。 |
| 眼睛 | `eye*` | 眼睛圖層與眼睛素材。 |
| 瀏海 | `hair_front_*` | 瀏海造型圖層。 |
| 眉毛 | `eyebrow_*` | 眉毛圖層。 |
| 嘴巴 | `mouth_*` | 嘴巴素材。 |
| 衣服 | `clothes_base_*` | 角色基礎服裝素材。 |
| 外套 | `clothes_outer_*` | 外套圖層。 |
| 鞋子 | `shoes_*` | 鞋子圖層。 |

部分素材以 `_mask`（可上色遮罩）和 `_line`（線稿）兩張圖成對使用；也有直接使用單張原色 PNG 的素材。資料夾內有些圖檔目前未列為商店商品，保留作為可用素材。

## 使用技術

- HTML5、CSS3、原生 JavaScript（Vanilla JavaScript），不使用前端框架。
- CSS Flexbox／Grid、Media Queries 與 CSS Mask，用於響應式版面及角色圖層上色。
- SVG：由 JavaScript 動態產生收成紀錄中的番茄圖示。
- `localStorage`：在使用者的瀏覽器保存網站資料。
- HTML `<dialog>`：呈現自訂計時及購買確認視窗。
- Font Awesome 6.4.0 CDN：提供介面圖示。
- Google Fonts：使用 Nunito 與 Noto Sans TC 字型。
- EyeDropper API：在支援的瀏覽器中吸取螢幕顏色；不支援時仍可使用自訂色盤。
- GitHub Pages：可部署此純靜態網站；不需要後端伺服器或建置指令。

## 上傳 GitHub Pages

本專案放在 `chiaolin1204/webdesign-pomodoro` repository 的 `shimin Max/` 子資料夾，不需要移動到 repository 根目錄。GitHub Pages 的發布來源仍設定為 repository 根目錄；Pages 會一併發布其中的子資料夾。

1. 將本專案檔案放在 repository 的 `main` 分支 `shimin Max/` 資料夾內，確認該資料夾包含 `index.html`、`style.css`、`tomoto.js`、`running-out-of-time.mp3` 和 `images/avatar/`。
2. 開啟 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 **Branch：`main`**、資料夾 **`/ (root)`**，再按 **Save**。這裡的 `/ (root)` 是 Pages 發布來源，並不代表要把本專案移出 `shimin Max/`。
5. 等待 GitHub Pages 部署完成後，從以下網址開啟此專案：  
   `https://chiaolin1204.github.io/webdesign-pomodoro/shimin%20Max/`
6. 後續更新 `shimin Max/` 內的檔案並推送到 `main` 分支後，GitHub Pages 會重新部署。

## 備註

- 任務、金幣與收成等資料只保存在目前瀏覽器的 `localStorage`，不會自動同步到其他裝置或瀏覽器；清除瀏覽器網站資料也可能一併移除這些資料。
- Font Awesome 與 Google Fonts 由外部 CDN 載入，使用時需要網路連線；若無法連線，網站核心互動仍由本地檔案提供，但外部圖示或字型可能無法顯示。
- GitHub Pages 對檔名大小寫敏感；HTML、CSS 和 JavaScript 中的圖片路徑需與上傳後的資料夾及檔名一致。
- HTML、CSS、JavaScript、音效和角色圖均使用相對路徑；保留 `shimin Max/` 下原有檔案與 `images/avatar/` 結構即可在上述子資料夾網址載入，不需要在路徑前加 `/`。
- 資料夾名稱含空格，網址中以 `%20` 表示；若重新命名資料夾，網站網址也會隨之改變。
